TagDrop

Get a .bin or .nfc file from your computer and write it to an NFC tag.

1 · Code from your computer
2 · Receiving
3 · Write to tag

Android: Chrome, writes tags right here. iPhone: open in Bluefy, then finish in NFC Tools. amiibo: finish in TagMo (Android) or Tagmiibo (iPhone). On your computer, run bananapeel run tagdrop to get a code.
